# аксиа — сайт

Статический сайт, перенесённый из Claude Design (холст «аксиа — сайт», артборд `Main.dc.html`).
Сборки нет: файлы отдаются как есть, поэтому сайт можно положить на любой хостинг или сервер (nginx, Apache, Vercel).

## Структура

```
index.html            — разметка страницы (внутри <template id="page">)
assets/css/site.css   — общие стили (сетка, секции, шрифт Soyuz Grotesk)
assets/css/page.css   — стили страницы (анимации, блоки «Решения», «Команда», форма)
assets/js/app.js      — логика: скролл-анимации, меню, календарь записи, формы
assets/js/dc-lite.js  — маленький движок, который рисует разметку из index.html через React
assets/js/vendor/     — React 18.3.1 (локально, без CDN)
assets/img/           — паттерны, «αξία», фото команды
assets/fonts/         — Soyuz Grotesk Bold (woff + otf)
```

Шрифты Golos Text и IBM Plex Mono подключаются с Google Fonts.

## Как править

- **Тексты и разметка** — `index.html`. Конструкции `{{имя}}` подставляются из `renderVals()` в `assets/js/app.js`;
  `<sc-if value="{{x}}">` показывает блок, если `x` истинно; `<sc-for list="{{xs}}" as="x">` повторяет блок.
- **Стили** — `assets/css/*.css`.
- **Поведение** — `assets/js/app.js` (обычный React-класс: `state`, `setState`, `renderVals()`).

## Локальный просмотр

```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Открывать `index.html` двойным кликом тоже можно, но шрифты лучше грузятся через сервер.

## Деплой

- **Vercel**: проект импортирован из этого репозитория, Framework Preset — *Other*, без build-команды. Каждый push в ветку
  создаёт превью-деплой.
- **Сервер клиента**: скопировать содержимое репозитория (кроме `.git`, `README.md`, `vercel.json`) в корень сайта.

## Что ещё не подключено

Формы записи на звонок и «напишите нам» пока ничего не отправляют, а свободные даты в календаре — пример
(так было в дизайне). Для боевого сайта нужен обработчик на сервере.
